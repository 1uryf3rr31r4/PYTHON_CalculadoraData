# Domínio Financeiro - Calculadora de Datas 🗓️

Um aplicativo feito em Python com interface gráfica (Tkinter), que permite realizar operações úteis com datas de forma visual, simples e funcional.

---

## 🚀 Funcionalidades

✅ Calcular diferença entre duas datas  
✅ Somar dias a uma data  
✅ Subtrair dias de uma data  
✅ Descobrir o dia da semana de uma data  
✅ Interface amigável com campos visuais (opcional: `tkcalendar`)  

---

## 🛠️ Tecnologias

- Python 3
- Tkinter
- tkcalendar (opcional)
- datetime

---

## ▶️ Como usar

```bash
pip install tkcalendar  # se for usar o calendário visual
python calculadora_datas.py
